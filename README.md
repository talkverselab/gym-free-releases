# Gym Free — 배포 전용 저장소

맨몸운동 코치 앱 **Gym Free**의 안드로이드 빌드만 올라오는 곳입니다.
**소스 코드는 여기 없습니다.** 비공개 저장소에서 GitHub Actions가 빌드해 이곳 릴리스로 보냅니다.

## 내려받기

최신 빌드는 항상 [`latest` 릴리스](../../releases/tag/latest)에 있습니다.

| 파일 | 설명 |
|---|---|
| `app-latest.apk` | 서명된 릴리스 APK |
| `latest.json` | 버전·빌드 번호·용량 등 메타데이터 (앱이 업데이트 확인에 씁니다) |

앱 안에서 **프로필 · 설정 → 앱 업데이트**로 들어가면 새 빌드를 확인해 바로 내려받아 설치합니다.
처음 설치할 때 한 번 「출처를 알 수 없는 앱 설치」 허용이 필요합니다 (안드로이드 정책).

## 앱 소개

- 맨몸·소도구·헬스기구 운동을 가르치고 ACSM 2026 권고에 맞춰 분할 스케줄을 짜줍니다.
- 운동은 카메라로 보지만 **영상은 저장하지 않습니다.** 33개 관절 좌표만 남고 얼굴도 색도 남지 않습니다.
- 모든 기록은 기기 안에만 저장되며 서버로 보내지 않습니다.
